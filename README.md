# FEMSA proofread delivery

Public static delivery of the approved ES–EN / ES–PT proofreading
corrections for the Coca-Cola FEMSA careers country pages.

Open [`proof-read-delivery/html/index.html`](proof-read-delivery/html/index.html).

The site keeps Spanish source fixed and switches target/correction between
English and Portuguese. Vercel serves only `proof-read-delivery/html/`.
